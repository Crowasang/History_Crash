# Git 컨벤션

## 1. 브랜치 이름

형식: `타입/작업이름` (슬래시 `/`로 구분, 작업 이름은 영어 소문자와 `-`)

| 타입 | 의미 | 예시 |
|------|------|------|
| `feat/` | 새 기능 추가 | `feat/player-dash` |
| `fix/` | 버그 수정 | `fix/jump-bug` |
| `docs/` | 문서 수정 | `docs/git-convention` |

- 브랜치는 항상 `dev`에서 만듭니다.

## 2. 커밋 메시지

형식: `타입: 내용` (콜론 `:` 뒤에 한 칸 띄우고, 내용은 한글로 간단하게)

| 타입 | 의미 | 예시 |
|------|------|------|
| `feat:` | 새 기능 추가 | `feat: 플레이어 대시 기능 추가` |
| `fix:` | 버그 수정 | `fix: 점프 중 이중 점프 되는 문제 수정` |
| `docs:` | 문서 수정 | `docs: 깃 컨벤션 추가` |

- 한 커밋에는 한 가지 작업만 담습니다.
